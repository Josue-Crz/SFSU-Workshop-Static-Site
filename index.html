HackStorm 2.0 - AI + IoT Track

SmartCane — AI IoT Hackathon

SmartCane is an AI-powered cane that gives blind and visually impaired users passive, always-on environmental awareness. Sensors mounted near the handle run continuously, forming a coverage cone from floor level to overhead so users do not need to sweep for every hazard. Built with teammate Nergiz Rahimzade, with hackathon mentorship from Hareesha KoratikereRameshappa, using Tuya T5-A1 boards provided by Tuya Smart.

2nd Place

Awarded in the AI + IoT Track at HackStorm 2.0 after a week of assistive technology hackathon work and rapid embedded-systems prototyping.

"We are living in the 21st century, with advanced technology around us in almost every field, and AI has become part of daily life. Yet blind people still have to sense the whole world with a cane. We wanted to maximize the efficiency and usage of the cane."

Setup, Local Server, and Common Errors

Run Locally

  1. Install dependencies: pip install flask opencv-python python-dotenv
  2. Add GROQ_API_KEY=gsk_... to .env.
  3. Run python tools/smart_cane_app.py.
  4. Open http://localhost:5000.

Useful Fixes

  • Install Flask if flask is missing.
  • Install OpenCV if cv2 is missing.
  • Try --camera 1 if camera index 0 is unavailable.
  • Check .env if Groq returns a 401 error.
